# Ильсур Зомби

Закрытая браузерная аркада для телефона, горизонтальная ориентация.

## Текущий этап

Задача 01: стартовый экран, временная арена, пауза, возврат в меню и подсказка поворота устройства. Боя, зомби, аккаунтов и серверного рейтинга пока нет. Отображаемое здоровье — макет. Все изображения созданы средствами CSS, внешних шрифтов и загрузок нет.

## Запуск

Нужен Node.js 22+ и npm. Внешних зависимостей нет.

```sh
npm run dev
```

Открыть http://localhost:5173. Для телефона подключиться к той же Wi-Fi сети и открыть `http://<LAN-IP-компьютера>:5173`, используя локальный IP компьютера. Доступ может потребовать разрешения локального брандмауэра. Компьютер должен оставаться включённым. Это локальная тестовая ссылка, не внешнее размещение.

## Сборка

```sh
npm run build
npm run preview
```

Готовая статическая сборка находится в `dist/`; локальная проверка — http://localhost:4173. Для постоянной ссылки нужно размещение `dist/` на HTTPS-хостинге. До реализации серверного входа не публиковать как закрытую игру: проверки пароля в текущем этапе нет.

## Проверка

```sh
npm test
```

`npm test` проверяет HTTP-сервер: MIME-типы, обработку ошибок и защиту от выхода за каталог.

Браузерные сценарии в `tests/shell.spec.js` предназначены для Playwright (при отдельной установке `@playwright/test` и браузеров: `npx playwright test`).

Ручные проверки: меню → арена → пауза → меню, поворот экрана, отсутствие горизонтального переполнения и доступность основных кнопок на размерах телефонов. Эмуляция не заменяет ручную проверку реальных iPhone/Safari и Android/Chrome.

## Структура

- `index.html` — семантические экраны.
- `src/main.js` — переходы, пауза при сворачивании, полноэкранный режим при поддержке браузером.
- `src/style.css` — оформление, адаптация, safe-area и подсказка поворота.
- `scripts/` — сервер разработки и сборка без внешних зависимостей.
- `tests/shell.spec.js` — проверки оболочки.

При повороте в портрет арена ставится на паузу; после возврата нужно нажать «Продолжить». Полноэкранный режим необязателен и показывается только при поддержке API.
